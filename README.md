# 更多编队 (MoreTeams)

为《明日方舟：终末地》普通编队界面扩充至 **20 个队伍**，支持为每个队伍设置自定义颜色与战术标记，完全沿用游戏原生的干员选择、改名与 3D 预览交互。

## 功能特性

- **20 编队扩展**：编队选择栏扩展为 4 行 × 5 列网格，位于分隔线上方，支持点击或键盘/手柄左右键快速切换。
- **个性化标记与配色**：
  - **元素配色**：支持默认及物理、灼热、电磁、寒冷、自然等元素主题色，呈半透明圆角平滑过渡。
  - **战术标记**：包含近卫、重装、辅助、术师、先锋、突击等职业标志及各类玩法图标，作为半透明底纹融入编队卡片中。
  - **便捷调色盘**：再次点击当前选中的编队即可呼出设置面板，支持实时切换并立即生效。
- **无缝原生集成**：
  - 前 4 队与游戏云端原生编队保持同步。
  - 第 5–20 队保存在本地，点击“启用编队”时无缝生效。
  - 干员配置、队伍改名均沿用游戏原生界面操作。
- **账号隔离存储**：本地编队数据按服务器与角色 ID 独立隔离存储，切换账号互不影响。

## 安装方法

1. 下载最新的 Release 压缩包。
2. 将压缩包解压到游戏根目录下的 `ZML/mods/more-teams/` 文件夹中。
3. 通过 ZML 启动器启动游戏即可。

> **说明**：此模组仅针对主世界普通编队生效；副本固定阵容、试用阵容及特殊挑战模式自动保留原生规则。
