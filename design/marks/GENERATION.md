# 战术标记设计规范

本文档记录编队战术标记的图标设计与图集构建规范。

## 视觉与图集规格

- **图集尺寸**：256 × 256 RGBA32 格式，划分为 4 × 4 网格，共 16 个 64 × 64 像素的单元格。
- **单元排布**：第 1 到 15 格依次对应 ID 2 到 16 的图标，最后一格（右下角）保持完全透明。
- **线宽与间距**：粗线条扁平设计，图标居中放置并预留适当安全内边距（Gutter），防止纹理采样溢出。
- **单色遮罩**：所有图标主体 RGB 值为纯白色 `(255, 255, 255)`，透明度通道（Alpha）控制线条轮廓，以便在游戏 UI 中根据选中/未选中状态动态着色。

## 导出与打包

设计源文件由打包脚本自动处理：
```powershell
python tools/pack-generated-marks.py
```
该脚本将图集图片转换为 Base64 编码并内嵌至 `mod/marks.lua` 中，避免产生外部松散图片资源依赖。
